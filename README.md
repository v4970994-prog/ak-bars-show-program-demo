# Ак Барс · Шоу-программа

## Рабочая версия V33.3

Код существующего Cloudflare Worker, тесты и инструкция публикации находятся в [worker/](worker/README.md). Исходник: [worker/src/worker.js](worker/src/worker.js). GitHub хранит код; рабочее приложение с D1 публикуется на Cloudflare.

## Статическое демо

Интерактивный прототип без регистрации через Telegram/MAX.

Все примеры, цены и пользователи вымышленные. Данные сохраняются только в localStorage вашего браузера. У разных посетителей разные независимые наборы данных; общий сервер отсутствует.

## Попробовать

1. Откройте опубликованный сайт GitHub Pages.
2. В верхней панели выберите роль: сотрудник, главный координатор, согласующий, наблюдатель или подрядчик.
3. Создайте событие и расчёт, выберите услуги, отправьте на согласование.
4. Переключите роли для прохождения этапов, скачайте Excel.
5. «Сбросить демо» возвращает исходные примеры.

Связывание аккаунтов, сохранение телефонов и отправка сообщений отключены. Не вводите реальные рабочие, финансовые или персональные данные. Переключатель роли — средство демонстрации, а не настоящая авторизация.

В корне репозитория находится статическое демо. В папке worker хранится код рабочей версии. Реальные токены, база, исходные финансовые материалы и внутренний аудит сюда не публикуются.

Excel: SheetJS 0.20.3 и ExcelJS 4.4.0, локальные копии в vendor. Лицензии см. THIRD-PARTY.md и vendor.
